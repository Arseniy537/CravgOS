CravgOS 0.9.0 - что изменилось (относительно 0.8.0)
===================================================

КОРОТКО
-------
1. Пиксельный режим: команда  wmboot  перезагружает систему в режим 1024x768 (VBE, 32 бита). Следующая загрузка снова обычная
   текстовая. В пиксельном режиме вся прежняя консоль (оболочка, gui, редактор) рисуется поверх пикселей.
2. cravgwm - плавающий оконный менеджер в стиле Openbox (команда  wm ). Устанавливается одной командой:  stas install cravgwm .
   Благодаря механизму зависимостей (--needs) автоматически устанавливается весь комплект оконного окружения.
3. Программы оконного окружения (входят в комплект cravgwm, настраиваются через XML-файлы в /etc/cravgwm/):
     cravgcomp (внутри cravgwm) - композитор, аналог picom: тени, прозрачность, скругление, плавное появление/исчезновение
     cravgbar   - панель задач, аналог tint2   cravgbg  - обои/градиент рабочего стола, аналог feh
     cravgfm    - файловый менеджер, аналог pcmanfm   cravgrun - быстрый запуск программ, аналог rofi
     cravgterm  - графический терминал         cwm-doc  - документация по конфигурации
4. Встроенная конфигурация "из коробки": при отсутствии пользовательских файлов в /etc/cravgwm/ оконный менеджер
   автоматически применяет полноценные настройки по умолчанию (панель cravgbar, фоновый градиент cravgbg, контекстное меню,
   разрешение запуска терминала в exec-allow и удобные сочетания клавиш: Alt+F4, Super+Return / Super+T, Super+D / Super+R,
   Super+E, Alt+Tab, Ctrl+Alt+BackSpace). Пользовательские XML-файлы требуются только для тонкой кастомизации.
5. Исправление стабильности VBE (wmboot): устранены зависания и чёрный экран при перезагрузке в пиксельный режим
   (корректная обработка регистра ES и прерываний STI при вызовах BIOS INT 10h, изоляция регистров VGA в ядре,
   первичная синхронизация фреймбуфера fbc_sync).
6. Файловая система стала больше: 128 файлов по 8192 байта (было 64 по 2048). Старый диск переносится автоматически при первой загрузке.
7. Пакеты stas поддерживают связки (--stas-bundle): много файлов за один запрос (cravgwm - 14 файлов, 54 КБ), а также зависимости (--needs).
8. Lua: побитовые операторы  & | ~ << >>  (унарный ~ тоже), куча Lua увеличена до 2,5 МиБ, добавлены расширения gfx.* и os.exec.
9. Версия 0.9.0 во всех компонентах ядра, загрузчиках (BIOS и UEFI bootx64.efi), сетевом User-Agent и интерфейсе.

КАК ПОЛЬЗОВАТЬСЯ (в виртуальной машине VirtualBox или QEMU с BIOS)
-----------------------------------------------------------------
    stas update
    stas install cravgwm         - установка всего оконного окружения одной командой (подтягивает все зависимости)
    wmboot                       - перезагрузка в пиксельный режим 1024x768x32 VBE
    wm                           - запуск оконного менеджера (сразу работает панель, фон, меню и хоткеи)
    Ctrl+Alt+BackSpace           - выход из WM обратно в консоль
    textboot                     - перезагрузка обратно в текстовый режим
    gfxinfo                      - показать видеорежим, адрес фреймбуфера и видеопамять

Горячие клавиши по умолчанию:
    Alt+F4                       - закрыть активное окно
    Super+Return, Super+T        - открыть графический терминал (cravgterm)
    Super+D, Super+R             - запустить лаунчер приложений (cravgrun)
    Super+E                      - открыть файловый менеджер (cravgfm)
    Alt+Tab                      - переключение между окнами
    ПКМ на рабочем столе         - контекстное меню приложений
    Ctrl+Alt+BackSpace           - экстренный выход из WM в консоль

Кастомизация и конфигурация (опционально):
    cwm-doc                      - справка по форматам XML-файлов настройки (3 страницы)
    mkdir /etc ; mkdir /etc/cravgwm ; edit /etc/cravgwm/rc.xml      - переопределение тем, клавиш и правил окон

Переключение "графическая оболочка / wm": в пиксельном режиме команда  gui  запускает классическую рабочую среду
(она рисуется поверх пикселей), команда  wm  - плавающий оконный менеджер. Между текстовым и пиксельным режимом
переключают wmboot / textboot (перезагрузка).

КЛЮЧЕВЫЕ ФАЙЛЫ НАСТРОЙКИ (применяются при наличии в /etc/cravgwm/)
   /etc/cravgwm/rc.xml        рабочие столы, фокус, тема, клавиши, мышь, правила окон, автозапуск
   /etc/cravgwm/menu.xml      меню (как в Openbox); встроенные: client-list-menu, client-menu
   /etc/cravgwm/cravgcomp.xml, cravgbar.xml, cravgbg.xml, cravgrun.xml, cravgterm.xml, cravgfm.xml
   /etc/cravgwm/exec-allow    список программ (путь /apps/имя), которым разрешён os.exec; терминал выполняет команды оболочки только если
                              в этом файле есть строка /apps/cravgterm. Разрешены только неинтерактивные встроенные команды.
Файлы настройки - до 8192 байт; внутри можно подключать другие:  <include href="/etc/cravgwm/другой.xml"/>

НОВЫЕ ФАЙЛЫ
-----------

                           консоль поверх пикселей и команды wm/wmboot/textboot/gfxinfo

tools/stas_bundle.py       собирает wm/<имя>/ в stas-repo/<имя>.stp (связка stas)
stas-repo/cravgwm.stp, cravgbar.stp, cravgbg.stp, cravgfm.stp, cravgrun.stp, cravgterm.stp, cwm-doc.stp   готовые связки
tests/test_gfx.c, test_wm.c, gfx_env.h, test_vbe_asm.py, gen_testfont.py, shots2png.py   тесты

ИЗМЕНЁННЫЕ ФАЙЛЫ
----------------
boot_iso.s   загрузчик BIOS: чтение и сброс одноразового флага CMOS 0x7D ('W'), безопасная инициализация VBE в Real Mode
             с сохранением ES и STI перед INT 10h, переключение режима 1024x768x32 LFB, передача структуры fbinfo и шрифта 8x16.
boot_efi.c   UEFI-загрузчик: обновлен баннер версии до Cravgos 0.9.0 (x86_64).
boot.s       добавлены символы fbinfo/romfont (сборка через GRUB работает в текстовом режиме без пикселей).
kernel.c     файловая система 128x8192 (формат диска версии 2 + перенос версии 1), клавиша Super и физический код клавиши (kbase),
             пиксельные координаты мыши, изоляция регистров VGA в пиксельном режиме, захват вывода команд (os.exec),
             команды wm, wmboot, textboot, gfxinfo, обновление версий и баннеров до 0.9.0.
fs.h         FS_MAXN 128, FS_FSZ 8192, обнуление данных при старте.
lua.h        точка расширения (LUA_EXT), побитовые операторы, куча 2,5 МиБ.
stas.h       пакеты-связки (--stas-bundle), зависимости (--needs), заголовки --members, удаление связок.
tools/stas_mkrepo.py, Makefile (make repo собирает связки и индекс), tests/run_all.py (+ test_gfx, test_wm), HANDOFF-1.md, README.md.

ПОВЕДЕНИЕ И ОГРАНИЧЕНИЯ (честно)
--------------------------------
* Модульные тесты, интерпретатор загрузчика VBE, эмуляция kernel.c на хосте и проверка отрисовки WM проходят со 100% успехом.
* Загрузчик bootx64.efi выводит диагностическую информацию UEFI GOP и готов к запуску на современных UEFI платформах.
* Пиксельный режим VBE требует BIOS/CSM с поддержкой линейного 32-битного кадрового буфера (LFB) и не менее 40–64 МиБ ОЗУ (VirtualBox и QEMU полностью поддерживаются).
* Образ диска использует формат версии 2. При первой загрузке 0.9.0 старый диск автоматически конвертируется.
* Файловый менеджер изменяет файлы только в /lua (песочница Lua-программ); просмотр доступен по всей файловой системе.
* Графический терминал cravgterm выполняет неинтерактивные команды оболочки согласно белому списку в /etc/cravgwm/exec-allow.
* Alt+Shift и Ctrl+Shift переключают раскладку RU/EN; горячие клавиши WM привязаны к физическим скан-кодам и работают независимо от раскладки.
