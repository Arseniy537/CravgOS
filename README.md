# Cravgos (CravOS) v0.9.0 (x86_64)

**Cravgos** — учебная автономная 64-битная операционная система (**x86_64 / AMD64 Long Mode**), написанная на freestanding Си и ассемблере без использования стандартной библиотеки (`libc`) и сторонних зависимостей.

ОС поддерживает гибридную загрузку (BIOS El Torito, UEFI x86_64 GOP, GRUB Multiboot 1 & 2), настраивает 4-уровневую страничную адресацию (PML4 Huge Pages 2 МБ) и переходит в 64-битный режим Long Mode (IA-32e).

В систему входят:
- **Два видеорежима**: классический текстовый VGA 80x25 и графический пиксельный режим VBE 1024x768x32 с линейным кадровым буфером (LFB).
- **Оконный менеджер `cravgwm`**: полноценное рабочее окружение в стиле Openbox (плавающие окна, композитор `cravgcomp`, панель `cravgbar`, обои `cravgbg`, меню и лаунчер `cravgrun`, эмулятор терминала `cravgterm`, файловый менеджер `cravgfm`), готовое к работе из коробки со встроенными настройками по умолчанию.
- **Классический рабочий стол `gui`**: оконный интерфейс с панелью задач, иконками и часами, работающий как в текстовом VGA, так и в пиксельном режиме поверх фреймбуфера.
- **Встроенный язык Lua**: интерпретатор стандарта Lua 5.3 (целые числа, побитовые операторы, сборщик мусора, куча 2,5 МиБ, графический API `gfx.*`, вызовы `os.exec`).
- **Сетевой стек с криптографией**: TCP/IP, Wi-Fi менеджер (`netmgr`, `wifi`), TLS 1.2, HTTP/1.0, DNS-over-HTTPS (DoH).
- **Веб-браузер `web`**: протоколы HTTP/HTTPS, парсинг HTML, перекодировки и рендеринг изображений (PNG, JPEG, GIF).
- **Пакетный менеджер `stas`**: пакеты-связки (`--stas-bundle`), автоматическое разрешение зависимостей (`--needs`), установка оконного окружения одной командой `stas install cravgwm`, офлайн-репозиторий и встроенный набор программ.
- **Файловая система RAMFS**: 128 файлов размером до 8192 байт каждый, формат диска ATA v2 с автомиграцией, двухпанельный менеджер `fm` и текстовый редактор `edit`.

## Что нового в версии 0.9.0

1. **Пиксельный режим VBE (1024x768x32) и консоль поверх пикселей**:
   - Команда `wmboot` устанавливает флаг в CMOS (0x7D == 'W') и перезагружает систему в пиксельный режим VBE 1024x768 с 32-битным цветом (линейный фреймбуфер LFB).
   - Команда `textboot` возвращает систему в классический текстовый режим VGA 80x25.
   - Команда `gfxinfo` отображает параметры текущего видеорежима, разрешение, адрес кадрового буфера и объем видеопамяти.
   - В пиксельном режиме вся текстовая консоль (шелл, вывод утилит, редактор `edit`, рабочий стол `gui`) автоматически рисуется поверх пикселей через модуль `fbcon.h`.
   - **Исправление wmboot (устранение чёрного экрана)**:
     - В загрузчике `boot_iso.s` гарантированно сбрасывается сегментный регистр `ES` перед обращениями к функциям VBE BIOS (INT 10h AX=4F00h / 4F01h).
     - Вызовы INT 10h выполняются с включёнными прерываниями (`sti`), инструкция `cli` перенесена строго после завершения `vbe_setup` перед переходом в защищённый режим.
     - В ядре (`kernel.c`, `fbcon.h`) добавлена изоляция портов VGA (0x3C4, 0x3CE, 0x3C0) — при активном режиме VBE манипуляции с регистрами знакогенератора и Blink-Off пропускаются во избежание сбоя видеочипа.
     - Добавлен немедленный первичный вызов `fbc_sync()`, исключающий темный экран при старте.

2. **Оконный менеджер `cravgwm` и экосистема приложений**:
   - Плавающий оконный менеджер в стиле Openbox: управление окнами (перемещение мышью и клавиатурой, изменение размеров, сворачивание, разворачивание на весь экран, закрытие).
   - Многослойный программный композитор `cravgcomp` (аналог picom): плавные тени, альфа-прозрачность, скругление углов, анимация открытия и закрытия окон.
   - Панель задач `cravgbar` (аналог tint2): список запущенных окон, переключатель виртуальных рабочих столов, системный лоток и часы.
   - Модуль обоев рабочего стола `cravgbg` (аналог feh): заливка, стильные цветовые градиенты и поддержка фоновых рисунков BMP.
   - Лаунчер быстрого запуска `cravgrun` (аналог rofi): интерактивный поиск и запуск программ по нажатию горячих клавиш.
   - Графический терминал `cravgterm`: выполнение консольных команд внутри оконного окружения.
   - Двухпанельный менеджер файлов `cravgfm` (аналог pcmanfm): навигация по каталогам, просмотр файлов и запуск скриптов.
   - Справочник `cwm-doc`: встроенная документация по конфигурированию XML.

3. **Упрощённая установка в одну команду**:
   - Больше нет необходимости устанавливать 7 отдельных пакетов вручную.
   - Достаточно выполнить:
     ```bash
     stas update
     stas install cravgwm
     ```
   - Механизм зависимостей `--needs` и связок `--stas-bundle` автоматически загружает и устанавливает все компоненты окружения: `cravgwm`, `cravgbar`, `cravgbg`, `cravgrun`, `cravgterm`, `cravgfm` и `cwm-doc`.

4. **Встроенная конфигурация "из коробки" (Defaults)**:
   - При отсутствии файлов в `/etc/cravgwm/` оконный менеджер больше не запускается с пустым экраном.
   - Из коробки активны: нижняя панель задач `cravgbar`, стильный фон рабочего стола `cravgbg`, контекстное меню по правому клику мыши и настроенный белый список `exec-allow` для терминала.
   - Стандартные горячие клавиши:
     - `Alt+F4` — закрыть активное окно
     - `Super+Return` / `Super+T` — открыть графический терминал (`cravgterm`)
     - `Super+D` / `Super+R` — открыть меню запуска приложений (`cravgrun`)
     - `Super+E` — открыть файловый менеджер (`cravgfm`)
     - `Alt+Tab` — переключение между окнами
     - `Ctrl+Alt+BackSpace` — экстренный выход из WM в консоль

5. **Файловая система RAMFS и диск ATA (формат v2)**:
   - Лимит файлов увеличен до 128 (ранее 64).
   - Лимит размера файла увеличен до 8192 байт (ранее 2048 байт).
   - Формат диска ATA обновлён до версии 2 с автоматической бесшовной миграцией данных старых версий (v1) при первом включении.

6. **Расширения Lua для графики и системы**:
   - Добавлена поддержка 64-битных побитовых операторов стандарта Lua 5.3: `&` (AND), `|` (OR), `~` (XOR / NOT), `<<` (сдвиг влево), `>>` (сдвиг вправо).
   - Объем кучи Lua увеличен до 2,5 МиБ (`lua_heap` в `.bss.xbig`).
   - Модуль `gfx.*`: поверхности ARGB, альфа-смешивание, линии, прямоугольники, текст растровым шрифтом 8x16, загрузка BMP, обработка очередей ввода с мыши и клавиатуры с модификаторами (Shift, Ctrl, Alt, Super).
   - Функция `os.exec`: контролируемый захват вывода системных команд.

7. **Синхронизация версий**:
   - Единая версия 0.9.0 во всех модулях: ядро, шелл, баннер UEFI `bootx64.efi`, сетевой стек (`User-Agent: Mozilla/5.0 (compatible; Cravgos/0.9.0; x86_64)`).

## Ключевые возможности

### 1. Загрузка и архитектура
* **Собственный BIOS-загрузчик (`boot_iso.s`)**: Real Mode (0x7C00) -> Protected Mode -> Long Mode (IA-32e) -> PML4 Huge Pages (2 МБ) -> GDT64. Поддерживает переключение VBE через флаг CMOS `wmboot`.
* **UEFI-загрузчик (`boot_efi.c` / `bootx64.efi`)**: 64-битное приложение UEFI с инициализацией GOP (версия 0.9.0).
* **GRUB Multiboot 1 & 2 (`boot.s`, `linker.ld`)**: бинарный образ `cravgos.bin` для загрузки через современные мультизагрузчики.
* **Гибридный ISO (`mkiso.py`)**: образ с двойной загрузкой (BIOS + UEFI El Torito) без внешних утилит.
* **64-битная обработка исключений (IDT)**: перехват 32 векторов с дампом всех 64-битных регистров `RAX..R15`, `RIP`, `RSP`, `RFLAGS` без вызова Triple Fault.
* **Энергонезависимое хранилище (ATA HDD)**: драйвер первичного контроллера ATA IDE (PIO 28-bit LBA), формат диска v2 (128 файлов по 8192 байта), сохранение состояния по команде `save` или автоматически.

### 2. Экран, темы и графические окружения
* **VGA 80x25**: Прямая работа с видеопамятью `0xB8000`, аппаратная кириллица (CP866), 16 цветов фона (Blink-Off).
* **VBE Linear Framebuffer 1024x768x32**: Графический слой `gfx.h` с аппаратным разрешением 1024x768 и глубиной цвета 32 бита на пиксель.
* **Консоль поверх пикселей (`fbcon.h`)**: Полноценная эмуляция текстовой консоли поверх графического фреймбуфера.
* **Оконный менеджер `cravgwm`**: Современное рабочее окружение с композитором, панелью задач, обоями, меню и поддержкой горячих клавиш.
* **Графический рабочий стол `gui`**: Классический оконный интерфейс с панелью задач, кнопками запуска и управлением мышью.
* **Цветовые схемы**: 8 встроенных тем (`dark`, `norton`, `retro`, `amber`, `light`, `tokyo`, `colorblind`, `solarized`).

### 3. Ввод-вывод и устройства
* **Клавиатура PS/2**: Скан-коды Set 1, аппаратный Caps Lock LED, клавиша Super, переключение раскладок **RU / EN** по `Alt+Shift`, `Ctrl+Shift` или `F12`.
* **Мышь PS/2**: Протокол IntelliMouse с защитой от рассинхронизации по таймауту 80 мс, поддержка колеса прокрутки, относительных и абсолютных координат.
* **Таймеры и часы**: PIT канал 0 (`delay_ms`, `now_ms`), CMOS RTC (дата и время UTC, флаг видеорежима 0x7D).
* **Сетевая карта Intel e1000**: Драйвер PCI (8254x, 8257x, I21x), кольца приёма и передачи.
* **PC Speaker**: Воспроизведение звуковых сигналов через канал 2 PIT (`beep`).

### 4. Сетевой стек и криптография
* **TCP/IP стек (`net.h`)**: Ethernet II, ARP, IPv4, ICMP (`ping`), UDP, DHCP, DNS (6 fallback серверов), TCP.
* **Сетевой менеджер (`netmgr`, `wifi`)**: Сканирование беспроводных сетей, подключение с паролем, аренда DHCP, пинг шлюза.
* **Криптография (`crypto.h`)**: SHA-256, HMAC-SHA256, AES-128, AES-GCM, X25519, NIST P-256.
* **TLS 1.2 (`tls.h`)**: Защищенное соединение ECDHE (X25519/P-256) + AES-128-GCM + SHA-256 с передачей SNI.
* **HTTP и DoH (`http.h`)**: Клиент HTTP/1.0, редиректы, Chunked Transfer, User-Agent `Cravgos/0.9.0`, DNS-over-HTTPS.

### 5. Браузер и декодеры графики
* **Веб-браузер `web`**: Протоколы `http://` и `https://`, разбор HTML, перекодировка кодировок (UTF-8, CP1251, KOI8-R), кликабельные гиперссылки, колесо мыши, до 6 изображений на страницу.
* **Декодеры (`image.h`)**: PNG (включая интерлейс Adam7 и zlib inflate), JPEG (baseline и progressive DCT), GIF (LZW), дизеринг по Байеру.

### 6. Встроенный язык программирования Lua
* **Интерпретатор Lua 5.3-like (`lua.h`)**:
  - Типы: `nil`, `boolean`, `integer` (64 бита), `string`, `table`, `function`.
  - Побитовые операторы: `&`, `|`, `~`, `<<`, `>>`.
  - Стандартные библиотеки `string`, `table`, `math`, `os`, `term`, `fs`.
  - Графическая библиотека `gfx.*`: создание поверхностей, рисование примитивов, текст, блиттинг, события мыши и клавиш.
  - Безопасная среда: файловые операции ограничены `/lua`, захват команд через `os.exec`.

### 7. Пакетный менеджер STAS
* Поддержка пакетов-связок (`--stas-bundle`) и древовидных зависимостей (`--needs`).
* **Каталог пакетов**:
  - Утилиты и игры: `dice`, `tower`, `math`, `bench`, `fact`, `guess`, `nim`.
  - Среда Lua: `luaide`, `tetris`, `calendar`.
  - Оконное окружение: `cravgwm`, `cravgbar`, `cravgbg`, `cravgrun`, `cravgterm`, `cravgfm`, `cwm-doc`.
* Офлайн-установка (`stas repo offline`) и работа с сетевыми репозиториями (`stas update`, `stas install`).

### 8. Основные команды системы
* **Системные**: `ver`, `about`, `help`, `setup`, `user`, `hostname`, `save`, `free`, `fastfetch`, `beep`.
* **Графика и WM**: `wmboot` (перезагрузка в VBE), `textboot` (перезагрузка в VGA), `wm` (запуск оконного менеджера), `gfxinfo` (информация о фреймбуфере), `gui` (классический десктоп), `theme` (смена цветовой темы).
* **Скриптинг**: `lua [файл/код]`.
* **Пакеты**: `stas update`, `stas list`, `stas info <пакет>`, `stas install <пакет>`, `stas remove <пакет>`, `stas run <пакет>`, `stas repo <url/offline/host>`.
* **Файлы и папки**: `ls`, `cd`, `pwd`, `mkdir`, `touch`, `cat`, `rm`, `cp`, `mv`, `tree`, `df`, `write`, `append`, `fm`, `edit`.
* **Сеть**: `ifconfig`, `dhcp`, `dns`, `ping`, `nslookup`, `curl`, `arp`, `lspci`, `netdiag`, `netmgr`, `wifi`, `web`.

## Сборка и запуск

### Требования
- `gcc` (64-битный MinGW-w64 на Windows или системный gcc на Linux с `-m64`)
- `binutils` (`as`, `ld`, `objcopy`)
- `python` 3.x

### Команды сборки
```bash
# Сборка всех целей (bootx64.efi, cravgos.iso, cravgos.bin)
make

# Сборка репозитория пакетов stas и офлайн-модулей
make repo

# Запуск кроссплатформенных модульных тестов
make test

# Очистка артефактов сборки
make clean
```

### Запуск в VirtualBox
1. **Параметры виртуальной машины**:
   - **Тип ОС**: `Other / Unknown (64-bit)`.
   - **Память**: не менее 64–128 МБ RAM (необходимо для VBE буфера и кучи Lua).
   - **Видеопамять**: не менее 16–32 МБ.
   - **Сеть**: `NAT`, тип адаптера: `Intel PRO/1000 MT Desktop (82540EM)`.
   - **Контроллер IDE/SATA**: виртуальный диск (ATA Primary Master) для сохранения данных.
2. **Запуск и использование**:
   - Подключить `cravgos.iso` к приводу виртуального диска и включить виртуальную машину.
   - Система загрузится в текстовом режиме VGA 80x25.
   - Для установки и запуска оконного окружения `cravgwm`:
     ```bash
     stas update
     stas install cravgwm
     wmboot
     wm
     ```
   - Для возврата в текстовый режим выполните `textboot`.
