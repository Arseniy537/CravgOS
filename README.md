# Cravgos (CravOS) v0.6.1 (x86_64)

**Cravgos** — учебная автономная 64-битная операционная система (**x86_64 / AMD64 Long Mode**), написанная на freestanding Си и ассемблере без использования стандартной библиотеки (`libc`) и сторонних зависимостей.

ОС поддерживает гибридную загрузку (BIOS El Torito, UEFI x86_64 GOP, GRUB Multiboot 1 & 2), настраивает 4-уровневую страничную адресацию (PML4) и переходит в 64-битный режим Long Mode (IA-32e). Включает собственный сетевой стек с шифрованием TLS 1.2, текстовый веб-браузер с рендерингом HTML и изображений (PNG, JPEG, GIF), графическое рабочее окружение (`gui`), пакетный менеджер `stas`, двухпанельный файловый менеджер и полноэкранный текстовый редактор.

## Что нового в версии 0.6.1

1. **Исправление сети, DNS и curl**:
   - **Устранена перезапись DNS**: при ручной установке `dns 8.8.8.8` флаг `ndns_manual = 1` предотвращает сброс настроек последующим фоновым DHCP.
   - **Многоуровневый DNS-fallback**: при ошибках SERVFAIL/REFUSED опрос продолжается по списку серверов: ручной/DHCP DNS -> шлюз (10.0.2.2) -> DNS VirtualBox NAT (10.0.2.3) -> Yandex DNS (`77.88.8.8`) -> Google DNS (`8.8.8.8`) -> Cloudflare (`1.1.1.1`).
   - **Мгновенный Chunked HTTP**: определение маркера окончания чанка (`0\r\n\r\n`) устранило 8-секундную задержку таймаута при скачивании веб-страниц.
   - **Прозрачный доступ к хосту**: при обращении к `127.0.0.1` или `localhost` в NAT-сети VirtualBox ядро автоматически перенаправляет запрос на шлюз хоста `10.0.2.2`.
   - **Приоритет DoH**: в резервном DNS-over-HTTPS первым опрашивается Google DNS (вместо заблокированного в РФ Cloudflare `1.1.1.1`).
2. **Пакетный менеджер stas**:
   - **Нормализация CRLF**: автоматическая очистка переводов строк Windows (`\r\n` -> `\n`) с проверкой SHA-256 для обоих вариантов предотвращает отказ при скачивании пакетов с Windows-серверов.
   - **Пресеты репозиториев**: быстрые команды `stas repo host` (ставит `http://10.0.2.2:8000`) и `stas repo default`.
   - **Встроенный офлайн-репозиторий**: команда `stas repo offline` позволяет устанавливать пакеты (`fact`, `guess`, `nim`) без необходимости подключения к интернету или поднятия локального HTTP-сервера.
3. **Поддержка GRUB и UEFI**:
   - **UEFI Bootloader (`boot_efi.c` / `BOOTX64.EFI`)**: 64-битное PE32+ приложение UEFI, запрашивает Graphics Output Protocol (GOP), определяет базовый адрес и разрешение фреймбуфера.
   - **Гибридный ISO (`mkiso.py`)**: генерирует образ FAT12 `efiboot.img` и записывает заголовок El Torito для платформы EFI (`0xEF`), обеспечивая загрузку как в Legacy BIOS, так и в UEFI.
   - **GRUB Multiboot 1 & 2 (`boot.s`, `linker.ld`)**: поддержка загрузки через `cravgos.bin` под управлением GRUB 2 с обработчиками прерываний и корректной раскладкой памяти `.bigbss`.
4. **Графическое окружение (`gui` / `desktop` / `gfx`)**:
   - Абстракция дисплея `struct fb_info` для подготовки к высокому разрешению.
   - Оконный менеджер рабочего стола: верхний таскбар, статус системы, часы, значки приложений, интерактивное окно с тенью, кнопками запуска файлов (`fm`), браузера (`web`), тем (`theme`), поддержкой горячих клавиш (1-4, F2, Esc) и мыши.
5. **Тестирование в виртуальной машине**:
   - Более 95% команд (39 команд) успешно протестированы напрямую в VirtualBox VM `cravgos060` с визуальным контролем скриншотов.

## Ключевые возможности

### 1. Загрузка и архитектура
* **Собственный BIOS-загрузчик (`boot_iso.s`)**: Real Mode (0x7C00) -> Protected Mode -> Long Mode (IA-32e) -> PML4 Huge Pages (2 МБ) -> GDT64.
* **UEFI-загрузчик (`boot_efi.c` / `bootx64.efi`)**: 64-битное приложение UEFI с инициализацией GOP.
* **GRUB Multiboot 1 & 2 (`boot.s`, `linker.ld`)**: бинарный образ `cravgos.bin` для загрузки через современные загрузчики.
* **Гибридный ISO (`mkiso.py`)**: образ с двойной загрузкой (BIOS + UEFI El Torito) без внешних утилит.
* **64-битная обработка исключений (IDT)**: перехват 32 векторов с дампом всех 64-битных регистров `RAX..R15`, `RIP`, `RSP`, `RFLAGS` без падения в Triple Fault.
* **Энергонезависимое хранилище (ATA HDD)**: драйвер первичного контроллера ATA IDE (PIO 28-bit LBA) с сохранением файлов RAMFS и настроек по команде `save`.

### 2. Экран, темы и графическое окружение
* **VGA 80x25**: Прямая работа с видеопамятью `0xB8000` и регистрами контроллера.
* **Аппаратная кириллица (`cyrfont.h`)**: загрузка растрового шрифта 8x16 (CP866) во 2-й слой (Plane 2) памяти VGA.
* **16 цветов фона (Blink-Off)**: разблокировка ярких фонов через регистры атрибутов `0x3C0`.
* **Псевдографика 80x50**: верхняя полуплашка `0xDF` (`▀`) позволяет рендерить картинки с эффективным разрешением 80x50 в текстовом режиме.
* **Цветовые схемы**: 5 встроенных тем (`dark`, `norton`, `retro`, `amber`, `light`).
* **Графический рабочий стол (`gui`)**: оконный интерфейс с панелью задач, иконками, кнопками и управлением мышью.

### 3. Ввод-вывод и устройства
* **Клавиатура PS/2**: скан-коды Set 1, переключение раскладок **RU / EN** по `Alt+Shift`, `Ctrl+Shift` или `F12`.
* **Мышь PS/2**: стандартный протокол и колесо прокрутки IntelliMouse, аппаратный/программный курсор.
* **Таймеры и часы**: PIT канал 0 (`delay_ms`, `now_ms`), CMOS RTC (дата/время UTC).
* **Сетевая карта Intel e1000**: PCI MMIO BAR0, кольца дескрипторов приёма и передачи.
* **PC Speaker**: воспроизведение мелодий через канал 2 PIT (`beep`).

### 4. Сетевой стек и криптография
* **TCP/IP стек (`net.h`)**: Ethernet II, ARP (кэш с автообновлением), IPv4, ICMP (`ping`), UDP, DHCP, DNS (UDP 53 с 6 серверами fallback), TCP.
* **Криптография (`crypto.h`)**: SHA-256, HMAC-SHA256, AES-128, AES-GCM (GHASH + CTR), X25519, NIST P-256 (secp256r1).
* **TLS 1.2 (`tls.h`)**: ECDHE (X25519/P-256) + AES-128-GCM + SHA-256 с передачей SNI.
* **HTTP и DoH (`http.h`)**: клиент HTTP/1.0, редиректы, Chunked Transfer, DNS-over-HTTPS (Google/Cloudflare).

### 5. Браузер и декодеры графики
* **Веб-браузер `web`**: протоколы `http://` и `https://`, парсинг HTML, перекодировка UTF-8/CP1251/KOI8-R в CP866, кликабельные ссылки, колесо мыши, до 6 изображений на страницу.
* **Декодеры (`image.h`)**: PNG (включая чересстрочный Adam7 и zlib inflate), JPEG (baseline и progressive DCT), GIF (LZW декомпрессия), 16-цветный дизеринг по матрице Байера.

### 6. Программы и утилиты
* **`gui`**: графическое рабочее окружение с панелью задач, часами и оконным менеджером.
* **`stas`**: пакетный менеджер (update, list, info, install, remove, run, repo) с поддержкой офлайн-режима и CRLF.
* **`fm`**: двухпанельный менеджер файлов с мышью и функциональными клавишами (F3–F10).
* **`edit`**: полноэкранный текстовый редактор с сохранением в RAMFS/диск.
* **Файловые утилиты**: `ls`, `cd`, `pwd`, `mkdir`, `touch`, `cat`, `rm`, `cp`, `mv`, `tree`, `df`, `write`, `append`, `save`.
* **Сеть и диагностика**: `fastfetch`, `netdiag`, `ifconfig`, `dhcp`, `dns`, `ping`, `nslookup`, `curl`, `arp`, `free`, `lspci`.
* **Мини-игры**: `guess`, `rps`, `snake`, `matrix`, `nim`, `fact`.

├── image.h              # Декодеры PNG, JPEG, GIF и дизеринг под 16 цветов VGA

├── stas.h               # Пакетный менеджер stas с офлайн-режимом и нормализацией CRLF
├── stas-repo/           # Репозиторий пакетов (index.txt, fact.stp, guess.stp, nim.stp)

├── tests/               # Модульные тесты, хост-эмулятор портов и фаззинг

    └── stas_mkrepo.py   # Генератор index.txt репозитория stas

## Сборка и запуск

### Требования
- `gcc` (64-битный MinGW-w64 на Windows или системный gcc на Linux с `-m64`)
- `binutils` (`as`, `ld`, `objcopy`)
- `python` 3.x

### Команды сборки
```bash
# Сборка всех целей (bootx64.efi, cravgos.iso, cravgos.bin)
make

# Запуск кроссплатформенных модульных тестов
make test

# Очистка артефактов сборки
make clean
```

### Запуск в VirtualBox
1. **Параметры виртуальной машины**:
   - **Тип ОС**: `Other / Unknown (64-bit)`.
   - **Память**: 64–128 МБ RAM.
   - **Сеть**: `NAT`, тип адаптера: `Intel PRO/1000 MT Desktop (82540EM)`.
   - **Контроллер IDE/SATA**: подключить виртуальный жесткий диск (ATA Primary Master) для сохранения данных.
2. **Загрузка**:
   - **Legacy BIOS**: подключить `cravgos.iso` к приводу DVD и запустить.
   - **UEFI**: включить галочку «Enable EFI» в свойствах машины — образ поддерживает загрузку через `\EFI\BOOT\BOOTX64.EFI`.
