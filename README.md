# Cravgos (CravOS) v0.6 (x86_64)

**Cravgos** — учебная автономная 64-битная операционная система (**x86_64 / AMD64 Long Mode**), написанная на freestanding Си и ассемблере без использования стандартной библиотеки (`libc`) и сторонних зависимостей.

ОС загружается напрямую с собственного ISO-образа, настраивает 4-уровневую страничную адресацию (PML4) и переходит в 64-битный режим Long Mode (IA-32e), содержит собственный сетевой стек с поддержкой шифрования TLS 1.2, текстовый веб-браузер с поддержкой HTML и декодированием изображений (PNG, JPEG, GIF) в 16 цветов VGA, двухпанельный файловый менеджер и полноэкранный текстовый редактор.

## Ключевые возможности

### 1. Загрузка и 64-битная архитектура
* **Собственный 64-битный загрузчик (`boot_iso.s`)**: 
  1. Стартует в 16-битном Real Mode на `0x7C00` (El Torito no-emulation).
  2. Включает линию A20 (Fast A20 Gate) и переходит в 32-битный Protected Mode.
  3. Проверяет поддержку инструкций 64-битного режима через CPUID (Long Mode bit).
  4. Формирует 4-уровневые таблицы страниц (PML4 -> PDPT -> 4xPD) в памяти `0x1000..0x7000`, отображая 4 ГБ физического адресного пространства через 2 МБ Huge Pages.
  5. Включает PAE (CR4.PAE), загружает CR3, активирует Long Mode в EFER MSR (`0xC0000080`, бит LME), включает страничную адресацию (CR0.PG).
  6. Загружает 64-битный GDT и выполняет дальний переход (`ljmp`) в полноценный 64-битный **Long Mode** (`.code64`).
* **Генератор ISO (`mkiso.py`)**: Сборка загрузочного ISO9660 с El Torito каталогом на чистом Python без необходимости в `xorriso` или `grub-mkrescue`.
* **Раскладка памяти (`linker_iso.ld`)**: Базовый образ размещается с адреса `0x7C00`, а большие рабочие буферы размером до ~2.8 МБ вынесены в секцию `.bigbss` по адресу `0x200000` (`NOLOAD`), благодаря чему размер файла ISO составляет всего ~150-200 КБ.
* **64-битная обработка исключений процессора (IDT)**: 16-байтные дескрипторы шлюзов прерываний (64-bit Interrupt Gates). Перехват всех 32 исключений x86_64 с сохранением всех 15 64-битных регистров (`RAX..R15`, `RIP`, `RSP`, `RFLAGS`) на выделенном стеке аварийного завершения. Вместо тройного сбоя (Triple Fault / перезагрузка) система выводит экран с полным дампом регистров и позволяет вернуться обратно в оболочку.

### 2. Экран, шрифт и графика
* **VGA 80x25**: Прямая работа с видеопамятью по адресу `0xB8000` и портами контроллера `0x3D4/0x3D5`.
* **Аппаратная кириллица (`cyrfont.h`, `tools/gen_cyr_font.py`)**: Прямая запись растрового шрифта 8x16 (72 глифа, CP866) во 2-й слой (Plane 2) видеопамяти через секвенсор VGA (`0x3C4/0x3C5`) и графический контроллер (`0x3CE/0x3CF`).
* **16 цветов фона (Blink-Off)**: Отключение режима мерцания через порт атрибутов `0x3C0` разблокирует 16 цветов фона для каждого знакоместа.
* **Псевдографика высокого разрешения**: Использование символа верхней полуплашки `0xDF` (`▀`) позволяет комбинировать цвет символа и цвет фона, превращая каждое знакоместо в два вертикальных пикселя. Это даёт виртуальное графическое разрешение **80x50** в чистом текстовом режиме!
* **Темы оформления**: 5 встроенных цветовых схем (`dark`, `norton`, `retro`, `amber`, `light`).

### 3. Ввод-вывод и устройства
* **Клавиатура PS/2**: Опрос портов `0x60/0x64`, обработка скан-кодов, переключение раскладок **RU (ЙЦУКЕН) / EN (QWERTY)** по `Alt+Shift`, `Ctrl+Shift` или `F12`.
* **Мышь PS/2**: Поддержка стандартного протокола и расширения IntelliMouse (колёсико). Программный курсор рисуется прямо в видеопамяти инверсией цветов ячейки.
* **Таймер PIT**: Опрос счётчика канала 0 (1193182 Гц) с миллисекундной точностью (`now_ms`, `delay_ms`).
* **CMOS / RTC**: Получение времени и даты, расчёт аптайма, энтропия для ГСЧ.
* **Сетевая карта Intel e1000 (82540EM)**: Сканирование шины PCI (`0xCF8/0xCFC`), инициализация MMIO BAR0 с 64-битными дескрипторами приёма (RX) и передачи (TX).
* **PC Speaker**: Воспроизведение звука через канал 2 PIT (`beep`).

### 4. Сетевой стек и криптография
* **TCP/IP стек с нуля (`net.h`)**:
  * Ethernet II, ARP (кэш на 8 записей с автообновлением).
  * IPv4, ICMP (клиент `ping`).
  * UDP, клиент DHCP (автоматическое получение IP, шлюза, маски и DNS).
  * DNS (клиент UDP порт 53).
  * TCP (клиентское соединение, SYN/ACK, отслеживание последовательностей, таймауты, скользящее окно).
* **Встроенная криптография (`crypto.h`)**:
  * Хеширование: SHA-256, HMAC-SHA256.
  * Симметричное шифрование: AES-128, AES-GCM (GHASH + CTR).
  * Асимметричные ключи: Curve25519 (X25519) и NIST P-256 (secp256r1).
* **Клиент TLS 1.2 (`tls.h`)**:
  * Хэндшейк ECDHE (X25519/P-256) + AES-128-GCM + SHA-256, передача расширения SNI.
  * Прозрачное шифрование и расшифровка сетевого трафика.
* **HTTP и DNS-over-HTTPS (`http.h`)**:
  * Клиент HTTP/1.0, поддержка редиректов (до 6), Chunked Transfer Encoding.
  * Резервный DoH через Cloudflare (`1.1.1.1`) и Google (`8.8.8.8`) на случай блокировок или сбоев классического DNS.

### 5. Браузер и декодеры изображений
* **Веб-браузер `web`**:
  * Поддержка протоколов `http://` и `https://`.
  * Парсер HTML, форматирование под 80 колонок, подсветка и кликабельность ссылок, скролл колёсиком мыши, переход по `G`, возврат по `B`.
  * Автодекодирование кодировок UTF-8, Windows-1251, KOI8-R в CP866.
  * Загрузка и показ до 6 картинок на страницу.
* **Декодеры графики (`image.h`)**:
  * **PNG**: Потоковый zlib inflate, поддержка RGB, RGBA, Grayscale, палитр и чересстрочной развёртки Adam7.
  * **JPEG**: Базовый (baseline) и прогрессивный (progressive) DCT, декодер Хаффмана, YCbCr -> RGB.
  * **GIF**: Декомпрессор LZW, локальные и глобальные палитры, interlaced.
  * **Квантование и дизеринг**: Преобразование произвольных изображений в 16-цветную палитру VGA с использованием матрицы Байера.

### 6. Встроенные программы и утилиты
* **`fm`**: Двухпанельный файловый менеджер в стиле Norton / Midnight Commander с поддержкой мыши и функциональных клавиш (`F3` просмотр, `F4` редактор, `F5` копия, `F6` перемещение, `F7` каталог, `F8` удаление, `F9` браузер, `F10` выход).
* **`edit`**: Полноэкранный текстовый редактор с установкой курсора кликом мыши.
* **RAMFS (`fs.h`)**: Файловая система в оперативной памяти (64 дескриптора по 2 КБ). Команды: `ls`, `cd`, `pwd`, `mkdir`, `touch`, `cat`, `rm`, `cp`, `mv`, `tree`, `df`, `write`, `append`.
* **Диагностика**: `fastfetch` (сводка системы с логотипом, определением 64-битного процессора и палитрой), `netdiag` (полный тест сетевого тракта), `ifconfig`, `dhcp`, `arp`, `nslookup`, `ping`, `free`, `lspci`.
* **Мини-игры**: `snake` (змейка), `matrix` (скринсейвер «Матрица»), `guess` (угадай число), `rps` (камень-ножницы-бумага).

## Структура репозитория

```
cravgos/
├── boot.s               # Загрузчик для GRUB Multiboot с переходом в 64-битный режим
├── boot_iso.s           # Собственный загрузчик: 16-bit -> 32-bit -> 64-bit Long Mode + PML4 + IDT
├── crypto.h             # Криптографические примитивы (SHA-256, AES, GCM, X25519, P-256)
├── cyrfont.h            # Сгенерированный растровый шрифт 8x16 (CP866)
├── fs.h                 # Файловая система RAMFS
├── HANDOFF-1.md         # Технический статус и журнал разработки
├── html.h               # Парсер и рендерер HTML, перекодировщик текста
├── http.h               # Клиент HTTP/1.0 и DNS-over-HTTPS
├── image.h              # Декодеры PNG, JPEG, GIF и дизеринг под 16 цветов VGA
├── kernel.c             # 64-битное ядро, драйверы, командная строка, браузер, fm, edit
├── linker.ld            # Скрипт линковки под Multiboot
├── linker_iso.ld        # Скрипт линковки прямого ISO (с секцией .bigbss)
├── Makefile             # Кроссплатформенная сборка проекта (Linux / Windows)
├── mkiso.py             # Сборщик ISO9660 + El Torito на чистом Python
├── net.h                # Сетевой стек: ARP, IPv4, ICMP, UDP, DHCP, DNS, TCP
├── tls.h                # Клиент TLS 1.2
├── tests/               # Модульные тесты, хост-эмулятор портов и фаззинг
└── tools/
    └── gen_cyr_font.py  # Генератор растрового шрифта кириллицы
```

## Запуск в виртуальной машине (VirtualBox)

1. Создать новую виртуальную машину:
   * **Тип**: `Other / Unknown` (**64-bit**).
   * **Память**: 64–128 МБ RAM (достаточно даже 16 МБ).
   * **Загрузка**: BIOS (EFI отключён).
2. Настройка сети:
   * **Тип подключения**: `NAT`.
   * **Тип адаптера**: `Intel PRO/1000 MT Desktop (82540EM)`.
3. Подключить `cravgos.iso` в виртуальный CD-привод и запустить.

## Сборка из исходников

Для сборки требуются: `gcc` (64-битный, `-m64`), `binutils` (`as`, `ld`, `objcopy`) и `python`.

```bash
# Сборка загрузочного cravgos.iso
make

# Очистка артефактов
make clean

# Запуск в QEMU (если установлен)
make run
```
