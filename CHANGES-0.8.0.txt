CravgOS 0.8.0 - что изменилось (относительно 0.7.0 из вашего репозитория)
=========================================================================

КОРОТКО
-------
1. В ОС встроен язык Lua (урезанный, только целые числа). Команда:  lua FILE  или  lua CODE
2. Пакеты stas теперь могут быть программами на Lua (первая строка файла: --lua).
3. В stas-repo/ добавлены программы, которые ставятся через stas:
     luaide    - IDE для Lua (ставится вместе с модулями luaide-ui, luaide-hl, luaide-help, luaide-repl)
     tetris    - Тетрис (ставится вместе с модулем tetris-lib)
     calendar  - календарь
4. Эти программы встроены в ядро и для офлайн-режима (stas repo offline).
5. Версия поднята до 0.8.0.

КАК ПОЛЬЗОВАТЬСЯ
----------------
В ОС:
    lua print(6*7)                  - выполнить строку
    lua /lua/hello.lua              - выполнить файл
    stas update                     - скачать список пакетов (или: stas repo offline)
    stas install luaide             - поставит IDE и 4 модуля автоматически
    luaide                          - запуск (любой установленный пакет запускается по имени)
    stas install tetris             - Тетрис (+ tetris-lib)
    stas install calendar           - календарь

Клавиши программ:
    luaide   : стрелки - выбор файла, Enter или e - редактор, r - запустить, x - править и запустить,
               c - проверить синтаксис, n - новый файл, d - удалить, k - консоль Lua, h - справка, q - выход
    tetris   : стрелки влево/вправо - двигать, вверх - повернуть, вниз - ускорить, пробел - сбросить,
               p - пауза, q или Esc - выход. Рекорд хранится в /lua/.tetris
    calendar : стрелки влево/вправо - месяц, вверх/вниз - год, t - сегодня, g - перейти к дате, q - выход

ЧТОБЫ stas update РАБОТАЛ ЧЕРЕЗ GITHUB
--------------------------------------
Загрузите в репозиторий всю папку stas-repo/ (теперь в ней 15 пакетов и обновлённый index.txt),
а также все новые и изменённые исходники из этого архива. Файл index.txt нельзя править руками:
после любых изменений пакетов выполните  make repo  (или python3 tools/stas_mkrepo.py stas-repo
и python3 tools/stas_embed.py).

http.h          - User-Agent Cravgos/0.8.0.
stas-repo/index.txt - пересобран (15 пакетов; не превышает лимит 2048 байт).
tools/stas_mkrepo.py - описание пакета берётся и из комментария "-- имя - описание" (для Lua-пакетов).
Makefile        - kernel.o зависит от lua.h и stas_lua_pkgs.h; правило для stas_lua_pkgs.h;
                  новая цель  make repo.
tests/test_stas.c       - заглушка lua_run_src; проверки установки с зависимостями, запуска Lua-пакетов,
                          офлайн-режима (встроенные копии побайтно равны файлам репозитория).
tests/run_all.py        - добавлены test_lua и test_lua_apps.
tests/host_stas_main.c  - мок-сервер хост-стенда отдаёт ответ одним TCP-сегментом, поэтому в сценарии
                          оставлена только строка индекса nim (иначе переполнение).
README.md, HANDOFF-1.md - раздел "Что нового в версии 0.8.0" / раздел 12 (устройство, ограничения, тесты).

ЯЗЫК LUA В ОС
-------------
Есть:     nil, true/false, целые числа (64 бита), строки, таблицы, функции и замыкания; local, if,
          while, repeat, for (числовой и for-in), function, return, break; операторы + - * / // % ^ ..
          == ~= < <= > >= and or not #; вызовы f(x), obj:method(x), f"str", f{...}; метатаблицы
          (только __index); pcall, error, assert, load, dofile, tostring, tonumber, type, pairs, ipairs, next.
          string: len sub upper lower rep byte char find(без шаблонов) format(%d %s %c %x) reverse
          table:  insert remove concat sort unpack      math: floor abs max min random sqrt
          os:     time date ms sleep                    collectgarbage
          term:   clear at write put fill color cursor key getkey readline size + константы клавиш
                  (UP DOWN LEFT RIGHT ESC ENTER BS TAB DEL HOME END PGUP PGDN F1..F10)
          fs:     list read write append remove exists isdir mkdir   (запись и удаление - только в /lua)
          edit(путь) - открыть встроенный редактор (только файлы в /lua)
Нет:      дробных чисел (операция "/" делит нацело, как "//"), match/gsub/gmatch, goto, "...", корутин.
Память:   сборщик мусора; при нехватке памяти программа останавливается с сообщением "not enough memory".
Остановка: Esc прерывает программу, которая долго считает и не читает клавиатуру (пустой цикл тоже).
Безопасность: Lua-программы не могут обращаться к сети и писать вне каталога /lua.
Каталог /lua создаётся автоматически при запуске Lua. Файл в нём не может быть больше 2048 байт
(ограничение файловой системы) - большие программы делятся на модули через dofile("/apps/имя").

ОГРАНИЧЕНИЯ (честно)
--------------------
* Всё проверено на хост-стенде (настоящий kernel.c с эмулированными клавиатурой, экраном, часами и
  сетью) и модульными тестами. В виртуальной машине и на реальном железе я эту версию НЕ запускал,
  потому что у меня нет VirtualBox/QEMU. Образ ISO по вашей просьбе не собирался; собрать можно
  командой  make cravgos.iso  (проверено, что ядро собирается без ошибок).
* bootx64.efi не пересобирался (нужен mingw): баннер UEFI по-прежнему пишет 0.7.0.
* Всего 64 файла/папки в файловой системе: IDE с модулями занимает 5, Тетрис 2, календарь 1.
* Размер index.txt ограничен 2048 байтами (сейчас около 1800).
* Скорость интерпретатора не измерялась на реальной машине: это обход дерева разбора.
